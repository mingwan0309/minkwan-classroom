# 민관이교실

인스타에서 유행하는 "온라인 절"을 본뜬 1인칭 3D 교실. 민관쌤(사진 얼굴을 입힌 선생님)이 교실 앞에서 감독하고, 학생은 교실을 돌아다니며 **책상을 엎고, 의자를 던지고, 숙제를 찢는** 등 교실을 파탄낼 수 있다. 선생님은 앞에서 말로만 말린다. **3분마다 교실이 원래대로 돌아오고**, 칠판에 그 카운트다운이 크게 뜬다.

**학원 홈페이지(my-homepage)와 완전히 별개인 사이트.** 학원 로그인·학원 Firebase(mkmath)와 아무 연결이 없다. 서버·DB 없이 index.html 하나로 돈다(순위표는 2026-10-31에 없앰).

## 파일
| 파일 | 역할 |
|---|---|
| index.html | 교실 전체 (Three.js r128 + cannon.js 0.6.2 물리, 둘 다 cdnjs) |
| face.png | 선생님 얼굴 (메인화면사진.jpg에서 얼굴만 타원으로 잘라낸 것 — 사진을 바꾸려면 이 파일만 교체) |

## 조작
- PC: WASD/방향키 + 마우스(클릭하면 마우스 잠금, 안 되는 브라우저는 끌어서 둘러보기), Shift 빨리 걷기, **F 또는 클릭 = 파탄 행동**, E 앉기/일어서기.
- 폰: 왼쪽 아래 조이스틱 + 화면 끌기 + 오른쪽 아래 **빨간 버튼**(물건을 바라보면 뜸) + 앉기 버튼.
- 이름은 선택(선생님이 말풍선에서 불러줌, 이 기기에 기억 `mk_class_name`).

## 파탄 행동 (물건 앞에서 바라보면 버튼이 뜸)
| 물건 | 버튼 | 동작 |
|---|---|---|
| 책상 16개 | 💥 책상 엎기 | 위로 들리며 바깥쪽으로 뒤집힘 (위에 있던 책·숙제도 같이 날아감) |
| 의자 16개 | 🪑 의자 던지기 | 손에서 바라보는 방향으로 날아감 |
| 책 | 📕 책 던지기 | 〃 |
| 숙제 8장 | 📄 숙제 찢기 | 3×3 조각으로 찢겨 팔랑팔랑 떨어짐 (조각마다 원래 숙제 그림의 그 부분이 보임) |
| 분필 3개·칠판지우개 | 🤍 / 🧽 던지기 | 칠판 받침 위에 있음 |
| 교탁 + 출석부 | 💥 교탁 엎기 | 무거워서 덜 날아감 |
| 쓰레기통 (앞 오른쪽) | 🗑 쓰레기통 차기 | 차이면서 종이뭉치 7개가 쏟아짐 |
| 축구공 (뒤 왼쪽) | ⚽ 공 차기 | 통통 튐 |

- 바라보는 물건 고르기: 화면 가운데 조준점에서 광선(2.8m) → 없으면 1.5m 안, 앞쪽 각도 안에서 가장 가까운 것(`findTarget`).
- 물리: 모든 물건이 cannon.js 몸체를 가지고 처음엔 잠들어 있다가(움직임 없음) 건드리면 깨어남. 플레이어·선생님은 KINEMATIC 상자라 걸어가면 의자·공을 밀어내고, 선생님이 날아온 물건에 세게 맞으면 휘청이며 "아야!".
- 책상·교탁은 지금 놓인 자리 기준으로 플레이어가 못 지나감(`buildDynColliders`).
- 벽 밖으로 빠진 물건은 즉시 제자리로.

## 선생님 (앞에서 말로만 말림)
- 교실 앞에서만 왔다갔다(예전의 가운데 통로 순찰은 없앰).
- 물건마다 말리는 대사가 다름(`CHAOS` 객체). 연달아 많이 하면(`heat` 4 이상) "그만!!! 진짜 그만!!" 같은 화난 대사 + 멈춰 서서 내 자리를 가리킴.
- 너무 돌아다니면 혼나는 "👀 선생님 눈치" 게이지는 그대로(`WARN_AT` 14m).
- 소리: 선생님 말은 브라우저 음성, 효과음(쿵·휙·찢는 소리·정리 종소리)은 WebAudio로 직접 만든 소리(파일 없음). 🔊 버튼으로 끔.

## 3분 원상복구
- **실제 시계 기준** 180초마다(`CYCLE`) — 모든 기기가 같은 순간에 리셋됨.
- 칠판 전체가 카운트다운(`drawBoard`, 매초 다시 그림), 마지막 10초는 빨갛게 깜빡임. 화면 위쪽 🧹 칩에도 같이 표시.
- 리셋 순간: 화면이 하얗게 번쩍 + 종소리, 흩어진 종이 조각·종이뭉치는 사라지고, 움직인 물건은 1.3초 동안 둥실 떠서 제자리로 돌아감(찢은 숙제는 제자리에서 다시 커지며 나타남) → 선생님 "자, 다 원래대로 돌려놨다…".

## 같이 접속 (다른 학생이 보이고 머리 위에 이름)
- 배포: GitHub Pages https://mingwan0309.github.io/minkwan-classroom/ (저장소 `mingwan0309/minkwan-classroom`, main 브랜치 루트).
- 교실 전용 Firebase 프로젝트 `minkwan-classroom`의 **Realtime Database**(싱가포르) 사용 — 학원 mkmath와 무관. 설정값은 index.html `FB_CONFIG`.
- `players/{netId}` = `{n 이름, x, z, y 방향, s 앉음, t 서버시각}`. 움직일 때 초당 8번, 가만히 있으면 10초마다 보냄. 창을 닫으면 `onDisconnect`로 자동 삭제, 40초 넘게 소식 없는 사람은 숨김. 최대 40명 그림.
- 다른 학생은 교복색 캐릭터 + 머리 위 이름표(이름 안 적으면 "친구"). 걷기·앉기 동작도 보임.
- **보이는 건 위치·이름뿐이고, 엎고 던진 물건은 각자 화면에서만 움직임**(물리는 기기마다 따로). 3분 원상복구는 실제 시계 기준이라 모두 동시에 일어남.
- 규칙: `database.rules.json` 내용을 Firebase 콘솔 → Realtime Database → 규칙 탭에 붙여넣기.
- Claude 링크(아티팩트) 판은 외부 서버 접속이 막혀 있어 같이 접속이 안 되고 혼자 하는 교실로 나옴.
