# 민관이교실

인스타에서 유행하는 "온라인 절"을 본뜬 1인칭 3D 교실. 민관쌤(사진 얼굴을 입힌 선생님)이 교실 앞에서 감독하고, 학생은 교실을 걸어 다니다 파란 내 자리에 앉아 공부한다. 너무 돌아다니면 선생님이 "자리에 앉아서 공부하자!"라고 함.

**학원 홈페이지(my-homepage)와 완전히 별개인 사이트.** 학원 로그인·학원 Firebase(mkmath)와 아무 연결이 없다.

## 파일
| 파일 | 역할 |
|---|---|
| index.html | 교실 전체 (Three.js r128, cdnjs) |
| face.png | 선생님 얼굴 (메인화면사진.jpg에서 얼굴만 타원으로 잘라낸 것 — 사진을 바꾸려면 이 파일만 교체) |
| firebase-config.js | 교실 전용 Firebase 설정값. 비어 있으면 교실은 그대로 되고 순위표만 "준비 중" |
| firestore.rules | 교실 전용 Firebase의 Firestore 규칙 (콘솔 → 규칙 탭에 통째로 붙여넣기) |

## 동작
- 입장할 때 이름 필수(12자, `/ . # [ ]`·띄어쓰기는 자동으로 빠짐, 이 기기에 기억 `mk_class_name`).
- PC: WASD/방향키 + 마우스(클릭하면 마우스 잠금, 안 되는 브라우저는 끌어서 둘러보기), Shift 빨리 걷기, E 앉기/일어서기. 폰: 왼쪽 아래 조이스틱 + 화면 끌기 + 앉기 버튼.
- 걸은 거리가 "👀 선생님 눈치" 게이지에 쌓여 `WARN_AT`(14m)를 넘으면 선생님이 멈춰서 내 자리를 가리키며 혼냄(말풍선 + 브라우저 음성). 대사는 `LINES` 객체.
- 앉아 있는 동안 "오늘 공부한 시간"(이 기기에만, `mk_class_study_날짜`)과 **공부 누적 TOP 10**(Firestore `classroom_study`, 문서ID `n_이름`)이 쌓임. 30초마다 최대 60초씩 `increment`로 저장. 이름이 같으면 같은 기록으로 합쳐짐.
- 규칙: 읽기 공개, 쓰기는 로그인 없이 가능하되 지난 저장 이후 실제로 흐른 시간(+5초, 최대 60초)만큼만 늘릴 수 있고, 문서ID가 `n_`+이름과 정확히 같아야 함(남의 이름 선점 방지). 지우기는 콘솔에서만.
- 점검용 `window.__classroom`(player/teacher/say/setWander).
